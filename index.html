Quick Reference

Independent Variable (IV)

The one factor a scientist purposely changes or controls in an experiment, to see what effect it has.

Dependent Variable (DV)

The factor a scientist measures or observes. It may change because of the independent variable.

Hypothesis format

If (IV), then (DV).
